# E-commerce Admin Dashboard

A modern and responsive admin dashboard for e-commerce businesses, built with Next.js and Tailwind CSS. This dashboard provides everything you need to manage your online store effectively.

![E-commerce Admin Dashboard Preview](./banner.png)

## Features

- Complete e-commerce management system
- Modern and responsive design
- Dark/Light mode support
- Real-time data visualization
- User-friendly interface
- Secure authentication
- Product management
- Order tracking
- Customer management
- Sales analytics

## Tech Stack

- Next.js 15.x
- React 19
- TypeScript
- Tailwind CSS
- Chart.js
- React Icons

## Getting Started

1. Clone the repository
2. Install dependencies:
```bash
npm install
```
3. Run the development server:
```bash
npm run dev
```
4. Open [http://localhost:3000](http://localhost:3000) in your browser
